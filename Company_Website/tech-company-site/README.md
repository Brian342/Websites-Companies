# ByteWave — Simple Tech Company Website

This is a small static website to showcase a tech company: home, projects, team, and contact pages.

Preview locally:

1. cd into the `tech-company-site` folder
2. Run `python3 -m http.server 8000` (or any static server)
3. Open http://localhost:8000 in your browser

Files:
- `index.html` - Home (vision, mission, reviews)
- `projects.html`, `project1.html`, `project2.html` - Projects and working demos
- `team.html`, `member1.html`, `member2.html`, `member3.html` - Team pages
- `contact.html` - Contact form
- `css/styles.css`, `js/main.js` - Assets
